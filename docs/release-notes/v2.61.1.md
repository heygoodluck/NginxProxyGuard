## ⚠️ 업그레이드 전에 알아둘 것

- 접근 목록, 차단 IP, 익스플로잇 규칙, 지역 제한, 보안 헤더, URI 차단, 클라우드 제공자 IP 대역, WAF 예외에 nginx 설정을 깨는 값은 이제 저장되지 않습니다(400). 이미 저장돼 있던 그런 값은 설정에서 빠지고 컨테이너 로그에 경고가 남습니다. 접근 목록의 잘못된 차단 항목은 "모두 거부"로 바뀝니다.

## 고침

- 보안: 일부 설정 값이 검사 없이 nginx 설정에 들어가던 문제. 관리자가 아닌 역할에 권한을 나눠 준 설치라면 업데이트하세요.
- 영어 화면 일부(WAF 로그 상세 등)에 한국어가 나오던 문제. (#321)
- 로그 등록 API(`POST /api/v1/logs`)가 잘못된 값에 500을 내던 문제. 이제 400을 냅니다. (#325)
- 이벤트 스트림·롱 폴링처럼 60초 넘게 열려 있는 요청이 대시보드 평균 응답시간을 키우던 문제. (#324)

## ⚠️ Read before upgrading

- Values that would break the nginx config are no longer saved (400) for access lists, banned IPs, exploit rules, geo restrictions, security headers, URI blocks, cloud provider IP ranges and WAF exceptions. Such values already stored are left out of the config with a warning in the container log. An access list deny rule that cannot be written becomes "deny all".

## Fixed

- Security: some settings values reached the nginx config without being checked. If you give non-admin roles access, update.
- Parts of the English UI (such as WAF log details) showed Korean text. (#321)
- The log API (`POST /api/v1/logs`) answered 500 for invalid values. It now answers 400. (#325)
- Requests held open for more than 60 seconds, such as event streams and long polling, inflated the dashboard's average response time. (#324)
